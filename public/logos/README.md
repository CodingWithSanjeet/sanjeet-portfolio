## SVG Advantages:

- **Scalable**: Perfect quality at any size (50px to 500px+)
- **Lightweight**: Smaller file sizes than PNG/JPG
- **Crisp**: Always sharp on any display (including Retina)
- **Professional**: Clean, modern vector graphics
- **Theme-friendly**: Works great with your dark portfolio theme

## Usage:

The logos are displayed in the Experience section:
- **Company logos** (50x50px) appear in the main experience card header
- **Client logos** (35x35px) appear next to client project names
